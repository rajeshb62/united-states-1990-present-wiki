Overview

The Code Breaker is Isaacson’s reported life-and-science narrative centered on Jennifer Doudna, co-inventor (with Emmanuelle Charpentier and collaborators) of CRISPR-Cas9 gene editing. The Introduction opens on Doudna’s March 2020 Berkeley COVID “into the breach” mobilization; nine Parts then run from Hilo childhood and the code of life, through Mojica’s clustered repeats and yogurt-industry CRISPR, the 2012 Science papers and race with Feng Zhang/George Church, therapies and biohacking, public-scientist ethics, He Jiankui’s CRISPR babies, moral philosophy, field dispatches, and pandemic CRISPR diagnostics—closing on the 2020 Nobel Prize and a New Orleans epilogue on curiosity.
